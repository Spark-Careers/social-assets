# prompts/

The `/spark-weekly-content` skill writes the weekly claude.ai-ready prompt into this folder, one file per week:

```
2026-W23-prompt.md
2026-W24-prompt.md
...
```

Each file is a self-contained prompt you paste into a fresh claude.ai chat to receive that week's bundle (docx + 3 CSVs + 10 PNGs).

Committing these to the repo means every week's exact prompt is preserved — handy if you ever need to audit what was requested or re-run for parity.
